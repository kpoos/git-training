# References and source mapping

The course explanations and exercises are original. Use these primary sources
for deeper reading and alternative explanations.

## Git fundamentals

- [Git — Learn](https://git-scm.com/learn): Pro Git book, introductory videos,
  and cheat sheet.
- [Pro Git, Getting Started](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control):
  version-control concepts and the Git model.
- [Pro Git, Git Basics](https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository):
  repositories, recording changes, history, and remotes.
- [Pro Git, Branching](https://git-scm.com/book/en/v2/Git-Branching-Branches-in-a-Nutshell):
  branches, merging, and conflicts.
- [Pro Git, Undoing Things](https://git-scm.com/book/en/v2/Git-Basics-Undoing-Things):
  correcting local work and understanding undo operations.

## GitHub collaboration

- [GitHub Learn](https://learn.github.com/skills): GitHub's learning
  experience and skills catalog.
- [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow):
  branch-based collaboration from change to pull request.
- [About pull requests](https://docs.github.com/en/pull-requests/reference/pull-requests):
  proposing, discussing, and merging changes.
- [Reviewing proposed changes in a pull request](https://docs.github.com/en/pull-requests/how-tos/review-pull-requests):
  review workflow and feedback.
- [About forks](https://docs.github.com/en/pull-requests/reference/forks):
  contributing when you do not have write access to the upstream repository.
